# ХАТИНКА ЛАПОК

Проект являє собою веб-додаток притулку для домашніх тврин з особливстями, які
були покинуті господарями, або знайдені на вулиці, з вадами і травмами і
отримали прихисток у цьому притулку. За допомогою веб-додатку притулок "Хатинка
Лапок" намагається знайти для своїх підлеглих добрих, дбайливих господарів, які
готові прихистити тваринок у своїх домівках, любити їх і дарувати їм щастя. У
проекті використані наступні технології:

## інструкція з запуску

1️⃣ Вимоги \
Node.js версії 16+\
npm або yarn

Перевірка:\
`node -v\` `npm -v`

2️⃣ Клонування репозиторію\
`git clone https://github.com/OleksiiMarushchak/project-pets-are-friend.git\` \
`cd project-pets-are-friend`

3️⃣ Встановлення залежностей\
`npm install`

4️⃣ Запуск у режимі розробки\
`npm run dev`

Після запуску відкрий у браузері:\
http://localhost:5173

5️⃣ Збірка проєкту (production)\
`npm run build`

Зібрані файли будуть у папці:\
dist/

6️⃣ Перегляд production-збірки локально\
`npm run preview`

📌 Додатково\
Усі вихідні файли знаходяться в папці src/\
Точка входу: src/main.js\
HTML-файл: index.html
