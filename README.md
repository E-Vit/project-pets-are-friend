# Khata Paw Shelter

## Project Description
Khata Paw is a web application for a pet shelter that cares for animals abandoned by their owners, found on the streets, or with injuries. The application helps the shelter find caring owners ready to provide a loving home and ensure the animals’ happiness.

## Technologies
- JavaScript  
- HTML5 / CSS3  
- Git / GitHub  
- Vite  

## Libraries Used
- Axios  
- CSS Star Rating  
- iziToast  
- SweetAlert2  
- Accordion-js  
- Swiper  
- TUI-Pagination  

## My Contribution
This is a group project completed during training. My contribution focused on the **Hero section**, specifically:  
- Creating semantic HTML structure for the section  
- Styling and responsive layout for mobile, tablet, and desktop  
- Implementing a background image with gradient  
- Positioning content according to the Figma design  
- Implementing an anchor button with hover and focus states according to the UI Kit  

## Getting Started

### 1️⃣ Requirements
- Node.js v16+  
- npm or yarn  

Check installed versions:
```bash
node -v
npm -v
2️⃣ Clone the repository
git clone https://github.com/OleksiiMarushchak/project-pets-are-friend.git
cd project-pets-are-friend
3️⃣ Install dependencies
npm install
4️⃣ Run in development mode
npm run dev
Open in your browser: http://localhost:5173

5️⃣ Build for production
npm run build
Built files will be in the dist/ folder.

6️⃣ Preview production build locally
npm run preview
Additional Information
All source files are in the src/ folder

Entry point: src/main.js

Main HTML file: index.html



# Хатинка Лапок

## Опис проєкту
Проєкт «Хатинка Лапок» — це веб-додаток для притулку домашніх тварин, який піклується про тварин, покинутих господарями, знайдених на вулиці або з травмами. Додаток допомагає притулку знаходити дбайливих господарів, готових подарувати тваринкам любов і турботу.

## Технології
- JavaScript  
- HTML5 / CSS3  
- Git / GitHub  
- Vite  

## Використані бібліотеки
- Axios  
- CSS Star Rating

- SweetAlert2  
- Accordion-js  
- Swiper  
- TUI-Pagination  

## Мій внесок
Це груповий проєкт, виконаний під час навчання. Мій внесок полягав у розробці секції **Hero**, зокрема:  
- Створення семантичної HTML-розмітки секції  
- Стилізація та адаптивна верстка для мобільних пристроїв, планшетів та десктопів  
- Додавання фонового зображення з градієнтом  
- Розміщення контенту відповідно до макету Figma
